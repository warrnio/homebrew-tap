# Warrn Homebrew Tap

Official Homebrew formulas for [Warrn](https://warrn.io).

## Install the CLI

```bash
brew install warrnio/tap/warrn
```

## Upgrade

```bash
brew update
brew upgrade warrn
```

Release binaries and checksums are published in
[warrnio/cli](https://github.com/warrnio/cli/releases).
